# 1. Pendahuluan

## 1.1 Tujuan Dokumen

Dokumen User Flow Specification digunakan untuk mendefinisikan alur perjalanan pengguna (user journey) pada Village Website CMS.

Dokumen ini menjadi dasar untuk:

1. Perancangan wireframe.
2. Perancangan antarmuka pengguna.
3. Penyusunan navigasi sistem.
4. Pengembangan frontend dan backend.
5. Pengujian pengalaman pengguna.
6. Validasi proses bisnis sistem.

---

## 1.2 Aktor Sistem

Village Website CMS memiliki dua aktor utama:

### Guest

Pengguna umum yang mengakses website tanpa proses autentikasi.

Hak akses:

* Melihat informasi desa.
* Membaca berita.
* Melihat galeri.
* Mengunduh dokumen publik.
* Melihat peta lokasi.
* Mengirim pesan narahubung.
* Menggunakan fitur pencarian.

### Admin

Administrator website yang mengelola seluruh konten dan konfigurasi sistem.

Hak akses:

* Mengelola halaman.
* Mengelola berita.
* Mengelola galeri.
* Mengelola dokumen.
* Mengelola media.
* Mengelola menu.
* Mengelola lokasi.
* Mengelola pesan.
* Mengelola pengaturan website.
* Melihat audit log.

# 6. Kesimpulan

User Flow Specification Village Website CMS mendefinisikan seluruh perjalanan pengguna yang akan didukung oleh sistem.

Dokumen ini menjadi acuan utama dalam penyusunan:

* Wireframe Specification
* Information Architecture
* Desain UI/UX
* Struktur Navigasi
* Pengembangan Frontend
* Pengembangan Backend
* Pengujian Sistem

Seluruh user flow dirancang berdasarkan konsep:

* Single Village Installation
* Single Administrator
* Guest Access Without Login
* Dynamic Page Builder
* Mandatory Invisible Watermark
* Reusable Village Website CMS
* Mobile-First Experience
