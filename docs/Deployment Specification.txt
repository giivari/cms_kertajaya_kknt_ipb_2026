# 1. Pendahuluan

## 1.1 Tujuan

Dokumen ini mendefinisikan standar deployment, infrastruktur, hosting, domain, backup, dan operasional Village Website CMS.

Dokumen ini dirancang untuk memenuhi dua kebutuhan:

### Tahap 1

Deployment murah selama masa KKN.

### Tahap 2

Migrasi ke infrastruktur resmi desa setelah website diterima dan digunakan secara permanen.

---

# 2. Filosofi Infrastruktur

Village Website CMS menggunakan prinsip:

```text id="4wnnys"
Start Small
Scale Later
```

Artinya:

* murah saat awal;
* mudah dipindahkan;
* tidak bergantung vendor tertentu;
* siap ditingkatkan ketika kebutuhan bertambah.

# 24. Kesimpulan

Deployment Village Website CMS menggunakan pendekatan:

```text id="rf0f3v"
Murah Saat KKN
↓
Stabil Saat Digunakan
↓
Mudah Diserahkan
↓
Mudah Digunakan Ulang
```

dengan tujuan utama memastikan website dapat berjalan selama program KKN, mudah dipelihara oleh desa, dan siap berkembang menjadi website resmi desa di masa mendatang tanpa perlu membangun ulang sistem dari awal.
