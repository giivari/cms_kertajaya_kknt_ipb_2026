REVISI DOKUMEN VILLAGE WEBSITE CMS (YANG WAJIB SAJA)

1. HAPUS TABEL admin_recovery_codes
- Hapus dari ERD
- Hapus dari Data Dictionary
- Hapus dari SRS
- Hapus dari Use Case
Alasan:
- Sistem hanya memiliki 1 admin.
- Tidak ada fitur lupa password.
- Tidak ada recovery berbasis email.

2. HAPUS remember_token
- Hapus kolom remember_token pada tabel admins.
- Tidak perlu fitur Remember Me.
Alasan:
- Dashboard bersifat eksklusif.
- Keamanan lebih penting daripada kenyamanan login.

3. EMAIL ADMIN BERSIFAT OPSIONAL
- Email tidak digunakan untuk autentikasi.
- Login hanya menggunakan:
  - Username
  - Password
  - TOTP
- Email boleh digunakan untuk notifikasi pesan narahubung.

4. PERTAHANKAN STATUS KONTEN SEDERHANA
Status yang digunakan:
- published
- archived
- deleted (soft delete)

Jangan menambahkan:
- draft
- scheduled
- review
- pending

5. SEO TETAP SEDERHANA
